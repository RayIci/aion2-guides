# Every claim is cited against a shared source registry, and confidence comes from its sources

Sources live once in a shared registry, each with a stable id, a URL, a **Source type**, a language/region and an access date. Content cites them by id, either on a single **Claim** or for a whole section. The granularity follows the content: a skill value gets its own citation, while a section's general advice can share one. A claim's **Confidence** badge is worked out from its cited sources by the rule in `docs/sourcing.md`, not typed by hand. An author can only lower it (for example, to flag a source that looks outdated), never raise it. We chose a shared registry with derived confidence so that one dead or outdated source can be traced to every claim that depends on it, and so that badges can't drift away from the evidence. The owner asked for mostly **Verified** coverage, so the build reports how many claims sit at each confidence level.
