# Follow Global / NA-EU servers only; KR/TW sources need confirmation

The guide follows the Global / NA-EU servers' patch timeline and balance, and its text is English only. The Korean and Taiwanese servers get patches first and have the deepest community sources (e.g. Inven), but their numbers, timing and sometimes systems differ from Global. A KR/TW source can back a claim only when a Global source confirms that the same thing exists on Global, or when the claim's citation clearly labels it as KR/TW-derived. Such a claim is capped at **Community** confidence until Global confirmation arrives. KR/TW patch notes are the main way to see what's coming, so they are the usual basis for a **Staged** patch.

## Considered options

- **Both regions with a region toggle**: rejected, because it doubles the upkeep for every patch.
