# No copied game assets; text and outbound links only

The site does not host skill icons, item images, map screenshots or other NCSoft assets. Where a visual helps, the guide links to an external database or map page, or uses an original diagram drawn for the site. The repo and site are public (ADR-0001), so embedding game assets is a copyright grey area. Text plus links is also quicker to update for each patch, because images go stale with no one noticing.
