:::quick{title="Quick steps"}
1. Put your skills on the keys as in the bar below; no macro to create [!opinion].
2. Each key holds a combo row: pressing it uses the **bottom** skill that is ready, so you can spam one key for a whole combo [@corpus-macros-guide-2026-10].
3. Never put a no-cooldown skill at the bottom of a row: the row would never get past it [@corpus-macros-guide-2026-10].
4. Skills and Stigmas: the same as every PvE setup ([Level 45: set up](/classes/gladiator/setup#pve-skills-to-raise)) [!opinion].
:::

**Who it's for:** You want no macro at all. Each key still holds a short combo row: pressing it uses the bottom skill that is ready. [@corpus-macros-guide-2026-10; !opinion]

## How to play

::::play
1. Buff (1, 2), jump in (Q), Ruinous Blow (8) [@corpus-gladiator-pve-build-2026-10].
2. Rage Burst (7), then spam 5: it casts Overhead Slam while it can and Rending Blow otherwise [@corpus-macros-guide-2026-10; !opinion].
3. On packs, 6 knocks them down (Mocking Blade) or sweeps (Crushing Wave), then 5 again [!opinion].
4. Keep left mouse held for Keen Strike between presses [@gamingtools-build-gladiator-pve-2026-10].
::::
