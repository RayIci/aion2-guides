::::play
- **Skill Queue:** Settings → Combat → Controls → on [@gamingtools-build-gladiator-pve-2026-10].
- **Macro key:** Settings → Key Settings → General → Macro, bound to the free right mouse button; hold left mouse (generator) and right mouse (macro) together. In AION 1 Control Mode use a keyboard key instead [@gamingtools-build-gladiator-pve-2026-10].
- **Skill presets:** the endgame build uses three presets (farming, single target, group) that share one set of Daevanion boards [@gamingtools-build-gladiator-pve-2026-10].
- **Quick slots:** a slot holding several skills casts the first one that's ready, from the bottom row up [@gamingtools-build-gladiator-pve-2026-10].
